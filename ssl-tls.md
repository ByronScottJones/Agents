# SSL/TLS

Open this file only when working with SSL or TLS encrypted network connections.

## Configuration

- A corporate network may route traffic through a TLS-inspecting proxy such as Zscaler. You may need to use the proxy's CA certificate file, for example `$HOME/.ssh/zscaler/zscaler.pem`.
